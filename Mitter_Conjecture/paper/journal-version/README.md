# Journal version

`rank2dim3_wong_journal_en.tex` — the standalone journal-format manuscript,
`Constancy of the Wong Matrix for Three-Dimensional Finite-Dimensional
Estimation Algebras`.

It uses the standard `article` class and a self-contained
`thebibliography`, so it compiles on its own:

```sh
pdflatex rank2dim3_wong_journal_en.tex
pdflatex rank2dim3_wong_journal_en.tex
```

The IEEE Transactions version of the same work, with the shared `ref.bib`
and the `tCON2e.cls` class file, is one level up in `paper/`.
